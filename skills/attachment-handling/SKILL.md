# 附件处理

## 背景

- 框架已把话题内所有附件下载到本地，路径清单附在用户消息末尾；同一话题跨轮次的附件持续可见。
- 纯文本模型 Read 图片只会返回一个 URL，看不到图片内容。

## 图片（png/jpg/gif/webp/bmp）

1. 先 Read 图片文件 → 得到 URL。
2. 再用 analyze_image 工具分析该 URL → 得到图片内容。
3. 基于分析结果回答；不要只凭文件名猜测图片内容。

## 普通文件（文档/表格/代码等）

- 直接 Read 即可；大文件分段读，不要一次性全量读入。

## 输出

- 分析结论随正文回复；如生成衍生文件，保存到 outputs/ 并按主题+日期命名。
